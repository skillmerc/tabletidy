Tabletidy
InstallSample tablesGitHub

Pick a table on any web page. Get a clean spreadsheet.

  • Tabletidy is a Chrome extension that finds the tables and repeated lists on a page and lets you pick one.
  • Gemini Nano names and types the columns on your device in about a second. Nothing is uploaded for small tables.
  • Large tables go to Gemini in the cloud through Firebase AI Logic, with personal-data columns masked before the request is built.
  • Every run shows an On device or Cloud badge with the reason, then exports CSV or JSON with real numbers and ISO dates.
Install and try it on this pageSource on GitHub

Install (about 3 minutes)

Tabletidy is loaded as an unpacked extension in desktop Google Chrome 139 or newer. Full setup, including your own free Firebase project, is in the README.

  1. Clone github.com/skillmerc/tabletidy, add your Firebase web config, then run npm install and npm run build:ext.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and choose extension/dist.
  3. Come back to this page, click the Tabletidy toolbar button and press Scan this page.
  4. Pick a table below, press Tidy columns, check the badge, then export CSV or JSON.
